# ✈️ FlightBooking

FlightBooking is a flight booking application that allows users to search for flights and make reservations. The project also includes an AI-powered travel assistant and machine learning features.

The project aims to bring different features such as flight management, reservations, check-in, travel assistance, price prediction, no-show prediction, and overbooking recommendations together in a single system.

## 🚀 Features

* ✈️ Flight search and listing
* 🎫 Flight booking
* 👤 Passenger management
* ✅ Check-in
* 🤖 AI-powered Travel Agent
* 💬 Natural language travel queries
* 🌤️ Weather information
* 🍽️ Restaurant recommendations
* 🏨 Hotel recommendations
* 💰 Currency information
* 🗺️ Travel and itinerary recommendations
* 📊 Flight price prediction
* 🔍 Anomaly and price analysis
* 👥 No-show prediction
* 🛫 Overbooking recommendations
* 📈 Machine learning-based analysis

## 🤖 AI Travel Agent

FlightBooking includes an AI-powered Travel Agent that allows users to ask travel-related questions using natural language.

The agent analyzes the user's message, determines the appropriate intent, and processes the request accordingly.

### Supported Intents

* Restaurant
* Weather
* Hotel
* Transportation
* Currency
* Itinerary
* Attraction

For example, a user can ask:

> "I'm going to Istanbul. Can you recommend some good restaurants and places to visit?"

The system analyzes the user's request and generates an appropriate travel response based on the detected intent.
